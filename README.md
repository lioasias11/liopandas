# 📊 LioPandas

A lightweight data analysis project built without using **Python Pandas**.
It was build during a hackaton to improve my skills in python.
liopandas is used for exploring, cleaning, transforming, and analyzing structured datasets efficiently.

---

## 🚀 Overview

**LioPandas** is a data analysis project focused on real-world data manipulation workflows.  
It demonstrates practical skills in data cleaning, transformation, aggregation, and visualization.

Main capabilities:
- Data cleaning & preprocessing
- Handling missing values
- Grouping & aggregation
- Feature engineering
- Exploratory data analysis (EDA)
- Basic visualization with Matplotlib
- Converting into pandas and geopandas easily
- Extra - has an offline map feature to display geometries

---

## 🛠️ Tech Stack

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib

---

## 📂 Project Structure

```text
liopandas/
├── dataframe.py      # Core DataFrame class with pandas-like API
├── series.py         # One-dimensional labeled array
├── index.py          # Label-based indexing system
├── groupby.py        # Grouping and aggregation engine
├── merge.py          # Merging and joining DataFrames
├── io.py             # CSV and I/O operations
├── offline.py        # Geospatial rendering and offline maps
└── __init__.py      # Package entry point
```
